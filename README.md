# Análisis de Expresión Génica (RNA-Seq)

## Descripción del Proyecto
Este repositorio contiene el flujo de trabajo y los scripts necesarios para realizar un análisis de expresión génica a partir de datos de secuenciación de ARN (RNA-Seq).

## Objetivos
- Procesar y alinear lecturas (reads) de RNA-Seq.
- Cuantificar la expresión génica.
- Identificar genes diferencialmente expresados entre condiciones experimentales.

## Estructura del Repositorio
- `data/`: Contiene los datos crudos (raw data) y procesados.
- `scripts/`: Contiene los scripts de código para el análisis.
- `results/`: Aquí se guardan los resultados finales (tablas, gráficos).
- `docs/`: Documentación adicional del proyecto.

## Requisitos e Instrucciones de Uso
Para ejecutar este proyecto, necesitas tener instalado:
- Entorno UNIX (Linux o macOS)
- Python 3.x o R 4.x

Para ejecutar el análisis:
1. Clona el repositorio.
2. Coloca tus datos en la carpeta `data/`.
3. Ejecuta los scripts de la carpeta `scripts/`.
